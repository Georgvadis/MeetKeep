# MeetKeep

MeetKeep сохраняет записи встреч на компьютер: вставьте ссылку — и запись скачается в выбранную папку с тем же названием, что на сайте.

## Скачать

- **Windows x64:** [MeetKeep.exe](https://github.com/Georgvadis/Vidloader/releases/latest/download/MeetKeep.exe) — один файл, запускается сразу.
- **macOS Apple Silicon:** [MeetKeep-macOS.zip](https://github.com/Georgvadis/Vidloader/releases/latest/download/MeetKeep-macOS.zip) — распакуйте и перенесите `MeetKeep.app` в «Программы».

Ссылки ведут на последнюю версию; все версии — в [Releases](https://github.com/Georgvadis/Vidloader/releases). Python и FFmpeg отдельно устанавливать не нужно.

Приложения не подписаны. На Windows SmartScreen может предупредить о неизвестном издателе: **«Подробнее» → «Выполнить в любом случае»**. На macOS при первом запуске откройте **Системные настройки → Конфиденциальность и безопасность** и нажмите **«Всё равно открыть»**.

## Как пользоваться

1. Вставьте ссылку на запись в верхнее поле и нажмите **«Скачать»**.
2. Ход загрузки виден в разделе **«Загрузки»**, готовые записи — в **«Готово»**, неудачные — в **«Ошибки»**, откуда их можно повторить.
3. Качество и папку для записей можно поменять в **«Настройках»**.

Если файл с таким именем уже есть, к новому добавится « (2)». Поддержка сайтов зависит от [yt-dlp](https://github.com/yt-dlp/yt-dlp/blob/master/supportedsites.md). Видео с DRM не поддерживаются.

## Записи, для которых нужен вход

- **macOS:** в **«Настройки» → «Вход на сайт»** выберите браузер, в котором вы вошли на сайт (Chrome, Safari, Firefox…). MeetKeep возьмёт вход оттуда.
- **Windows + Chrome:** Chrome не даёт другим программам читать данные входа, поэтому используется расширение MeetKeep. Его ставят один раз:
  1. В MeetKeep откройте **«Настройки» → «Расширение Chrome»** и нажмите **«Открыть расширения Chrome»**.
  2. Включите **«Режим разработчика»**, нажмите **«Загрузить распакованное расширение»** и выберите папку, которую показывает MeetKeep.
  3. Закрепите значок MeetKeep. Теперь откройте встречу в Chrome и нажмите значок — запись начнёт скачиваться в MeetKeep вместе с её названием.
- **Windows + Firefox:** выберите **Firefox** в **«Настройки» → «Вход на сайт»**.
- **Другие случаи:** можно выгрузить из браузера файл `cookies.txt` и выбрать его в настройках.

Если вы раньше пользовались Vidloader, настройки и ключ расширения перенесутся сами. Само расширение нужно загрузить заново из новой папки, которую показывает MeetKeep.

## Сборка

Нужны Python 3.13+ и Node.js 22+.

- Windows: `build-windows.bat` → `dist\MeetKeep.exe`.
- macOS: `build-mac.command` → `dist/MeetKeep.app`.

Интерфейс написан на React (`frontend/`), окно приложения — [pywebview](https://github.com/r0x0r/pywebview), загрузка — yt-dlp и FFmpeg. GitHub Actions собирает обе версии в workflow [Build apps](.github/workflows/build.yml) при каждом изменении в `main`.

## Выпуск новой версии

1. Откройте [Actions → Build apps](https://github.com/Georgvadis/Vidloader/actions/workflows/build.yml) и нажмите **Run workflow**.
2. В поле версии укажите новый номер, например `v0.4.0`, и запустите.

Workflow соберёт обе версии, создаст тег и релиз «MeetKeep 0.4.0» со списком изменений и приложит `MeetKeep.exe` и `MeetKeep-macOS.zip`. То же произойдёт при пуше тега: `git tag v0.4.0 && git push origin v0.4.0`.
