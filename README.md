# Vidloader

Vidloader — утилита для скачивания видео по ссылке.

## Скачать

Готовые версии для **Windows x64** (один файл `Vidloader.exe`) и **macOS Apple Silicon** (приложение `Vidloader.app`) доступны в [Releases](https://github.com/Georgvadis/Vidloader/releases/latest). Python и FFmpeg отдельно устанавливать не нужно.

Приложения не подписаны. На Windows SmartScreen может предупредить о неизвестном издателе: **«Подробнее» → «Выполнить в любом случае»**. На macOS при первом запуске откройте **Системные настройки → Конфиденциальность и безопасность** и нажмите **«Всё равно открыть»**.

## Как пользоваться

1. Вставьте ссылку на видео.
2. В поле **«Вход на сайт»** выберите:
   - **«Не требуется»** — для открытых видео;
   - **«Окно входа Vidloader»** — для видео после входа (по умолчанию на Windows). Нажмите **«Открыть окно входа»**, войдите на сайт в открывшемся окне Chrome или Edge и, не закрывая его, нажмите **«Скачать видео»**;
   - **Chrome / Safari / Firefox** — на macOS Vidloader может взять вход прямо из вашего браузера.
3. Файл называется так же, как видео на сайте. Если файл с таким именем уже есть, к новому добавится « (2)».

Поддержка сайтов зависит от [yt-dlp](https://github.com/yt-dlp/yt-dlp/blob/master/supportedsites.md). Видео с DRM не поддерживаются.

## Окно входа

На Windows Chrome шифрует cookies так, что сторонние программы не могут их прочитать, поэтому Vidloader открывает отдельное окно Chrome (или Edge) со своим профилем и забирает cookies из него. Расширение для этого не нужно.

- Вход в окне сохраняется между запусками, но сайты, которые держат вход только до закрытия браузера, попросят войти снова.
- Пока окно входа открыто, другие программы на этом компьютере могут управлять им через локальный порт отладки. Закрывайте окно, когда оно не нужно.
- Если окно входа открыто на странице видео, файл получит название из заголовка этой страницы.

## Запасной вариант: расширение Chrome (только Windows)

Нужно, только если окно входа не работает, например его запрещает политика компании.

1. В Vidloader раскройте **«Запасной вариант: расширение Chrome»** и нажмите **«Настроить расширение»**. Откроется `chrome://extensions/`, а Vidloader покажет папку `extension`.
2. В Chrome включите **«Режим разработчика»**, нажмите **«Загрузить распакованное расширение»** и укажите эту папку. Закрепите значок Vidloader.
3. Откройте страницу видео в своём Chrome и нажмите значок. Vidloader должен быть запущен.

Если расширение было установлено из старой папки `Chrome extension`, удалите его и загрузите заново из папки `extension`.

## Сборка

- Windows: `build-windows.bat` → `dist\Vidloader.exe`.
- macOS: `build-mac.command` → `dist/Vidloader.app`.

GitHub Actions собирает обе версии в workflow [Build apps](.github/workflows/build.yml).
