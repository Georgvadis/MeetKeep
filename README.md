# Vidloader

Локальное приложение для macOS и Windows. Вставьте ссылку, выберите браузер с уже открытым доступом к сайту и нажмите «Скачать видео». Записи СберВидео вида `/meetups/…` приложение само переводит в адрес видеопотока. Для других сайтов работает всё, что поддерживает [yt-dlp](https://github.com/yt-dlp/yt-dlp/blob/master/supportedsites.md). Защищённые DRM потоки и сайты, которые не поддерживает yt-dlp, не скачиваются.

## Автономное приложение для Mac

Запустите `build-mac.command`, затем откройте `dist/Vidloader.app`. Python, yt-dlp и FFmpeg будут внутри приложения. Сборка предназначена для Mac с процессором Apple Silicon. Для входа на защищённые сайты выберите браузер, в котором вы уже авторизованы.

## Автономное приложение для Windows

Готовый `Vidloader.exe` можно скачать из артефактов успешного запуска [GitHub Actions](https://github.com/Georgvadis/Vidloader/actions/workflows/windows.yml). Он содержит Python, yt-dlp и FFmpeg; устанавливать их для запуска не нужно. Для самостоятельной сборки на Windows запустите `build-windows.bat`.

## Запуск из исходников на Mac

1. Установите [Homebrew](https://brew.sh/) и выполните `brew install python@3.14 ffmpeg`.
2. Дважды щёлкните `start-mac.command`. При первом запуске установятся зависимости, затем откроется окно приложения в браузере.
3. Для этой записи СберВидео выберите **Chrome** и включите «Пропустить проверку сертификата», если видите ошибку `CERTIFICATE_VERIFY_FAILED` из-за корпоративной HTTPS-защиты.

## Запуск из исходников на Windows

1. Установите [Python](https://www.python.org/downloads/windows/) с Python Launcher и [FFmpeg](https://ffmpeg.org/download.html); добавьте FFmpeg в `PATH`.
2. Дважды щёлкните `start-windows.bat`. При первом запуске установятся зависимости, затем откроется окно приложения в браузере.
3. Выберите браузер, в котором уже можете просматривать видео.

По умолчанию файлы попадают в `~/Downloads` (папка «Загрузки»). Файл с незавершённой загрузкой остаётся в папке для возобновления. Интерфейс общается только с локальным сервером на `127.0.0.1`; yt-dlp берёт cookies из выбранного браузера и обращается к сайту видео. Не публикуйте лог загрузки, если в нём оказались приватные ссылки.

## Сборка отдельного приложения

На Mac запустите `build-mac.command`: результат появится в `dist/Vidloader.app`. На Windows запустите `build-windows.bat`: результат появится в `dist/Vidloader.exe`. Сборку для каждой системы нужно запускать на самой системе. Готовые приложения включают Python, yt-dlp и FFmpeg: устанавливать их отдельно на компьютере, где запускается приложение, не требуется.

Кнопка «Закрыть приложение» завершает локальный сервер. Если скачивание идёт, сначала остановите его.
