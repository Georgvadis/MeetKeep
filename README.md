# Vidloader

Vidloader — утилита для скачивания видео по ссылке.

## Скачать

Готовые версии для **Windows x64** и **macOS (Apple Silicon)** доступны в [Releases](https://github.com/Georgvadis/Vidloader/releases/latest). Скачайте архив для своей системы, распакуйте его и запустите приложение. Python и FFmpeg отдельно устанавливать не нужно.

## Как пользоваться

1. Для видео без авторизации вставьте ссылку в Vidloader, выберите **«Не требуется»** в поле входа и нажмите **«Скачать видео»**.
2. На macOS для видео после входа выберите **Chrome** в Vidloader. На Windows один раз подключите расширение по инструкции ниже. Затем откройте видео в Chrome и нажмите значок Vidloader. Chrome можно не закрывать.

Поддержка сайтов зависит от [yt-dlp](https://github.com/yt-dlp/yt-dlp/blob/master/supportedsites.md). Видео с DRM не поддерживаются.

## Подключение Chrome на Windows

1. Запустите Vidloader и нажмите **«Настроить расширение»**. Откроется страница `chrome://extensions/`, а Vidloader покажет папку расширения.
2. В Chrome включите **«Режим разработчика»**, нажмите **«Загрузить распакованное расширение»** и укажите эту папку. Закрепите значок Vidloader на панели Chrome.
3. Откройте страницу видео и нажмите значок. Vidloader должен быть запущен; расширение передаёт ссылку и cookies только локально, без файла `cookies.txt`.

Расширение читает cookies текущего сайта после нажатия на значок. Если Chrome обновит страницу входа, войдите на сайт в Chrome как обычно и нажмите значок снова. Если после обновления Vidloader расширение перестало отвечать, нажмите **«Обновить»** на странице расширений Chrome.

На Windows прямое чтение cookies Chrome через `yt-dlp` может завершаться ошибкой DPAPI. Для этого случая используйте расширение. Ручной выбор `cookies.txt` оставлен как запасной вариант.
